旅程详情页布局方案

手机端如何在地图和行程列表之间切换？

A

底部抽屉式（推荐）

地图全屏展示，行程列表作为可拖拽的底部面板（DraggableScrollableSheet）。向上拖拽展开列表，向下收起看地图。

🗺️ 高德地图
第1天 · 3个地点
↑ 上拉展开列表
✓ 地图随时可见 · 体验最流畅
B

Tab 切换式

顶部两个 Tab："地图" 和 "行程"，点击切换。类似 Vue 移动端的 mapMode 布尔值做法。

🗺️ 地图
📋 行程
高德地图全屏
✗ 看列表时地图完全消失
C

地图缩略 + 列表

上方固定高度地图（约屏幕 40%），下方列表可滚动。地图和列表同时可见。

🗺️ 地图（40%）
第1天
📍 故宫博物院
🍜 全聚德烤鸭
🏨 北京饭店
△ 两者都偏小，操作不便
