导航结构与页面总览

Flutter 版路由结构，基于 GoRouter + Riverpod

路由树
/
├── /auth — 登录/注册（无需 token）
│ ├── /signin
│ └── /signup
├── /accept — 接受邀请（无需 token）
└── /travel — 主应用（需要 token）
├── /travel — 旅程列表
└── /travel/:id — 旅程详情
各页面功能
🔐 Auth（登录/注册）
  • MD5 密码哈希
  • 表单校验（async_validator）
  • token 写入 Riverpod + SharedPreferences
  • 支持邀请 token 透传
📋 旅程列表
  • 分页 + 搜索（防抖 500ms）
  • 旅程卡片（状态/时长/协作者）
  • 新建旅程对话框
  • 用户菜单（编辑/改密码/退出）
🗺️ 旅程详情（核心）
  • 高德地图 + 弹性标记
  • 日程列表（按天分组）
  • 行程 CRUD + 克隆
  • 搜索 POI → 添加行程
  • 协作者权限管理
  • 装备清单抽屉
  • 批量导入 / AI 采集
🎒 装备清单（抽屉）
  • 分组折叠展示
  • 勾选项目
  • 编辑模式：增删分组/条目
  • 套用模板重置

导航守卫：无 token → 重定向 /signin；有邀请 token → /accept → 自动跳转旅程详情
