A — 数字编号圆形 Marker

普通地点用橙色圆圈 + 序号，酒店用紫色圆圈 + 🏨。弹出卡显示名称、时间段、类型和第几站。简洁清晰，一眼知道顺序。

B — 水滴形 Marker + 名称标签

经典地图图钉样式，每个 marker 下方始终显示名称标签。弹出卡更丰富，有封面图区域。视觉更传统，但标签可能重叠。

C — 圆角方形 Marker + 虚线路径 + 底部信息条

Marker 为圆角方块，站点间用虚线连接表示行进顺序。点击 marker 后底部出现信息条（不遮挡地图）。路书感最强。
