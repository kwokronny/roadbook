长途交通信息来源

用户如何快速获取高铁/飞机的起终点、时间等信息？

A

12306 / 航司截图 OCR

用户截图订单页面，通过 OCR 识别车次/航班号、起终点、出发到达时间

优势

  • 信息最完整准确
  • 用户操作直观

劣势

  • 需要接入 OCR 服务（成本）
  • 不同 App 截图格式差异大
B

车次 / 航班号查询

用户输入 G1234 或 CA1234，自动查询时刻表获取起终点站和时间

优势

  • 输入简单，体验流畅
  • 数据结构化

劣势

  • 需要接入时刻表 API
  • 临时调整的班次可能不准
C

手动填写专用表单

专门设计一个长途交通表单，用户手动选择交通方式、输入起终点和时间

优势

  • 实现简单，无外部依赖
  • 用户完全可控

劣势

  • 输入繁琐
  • 体验一般
D

剪贴板 / 短信文本解析

用户粘贴 12306 短信或购票确认文本，自动提取车次、时间、起终点等关键信息

优势

  • 信息来源可靠（官方短信）
  • 解析规则相对固定

劣势

  • 仅覆盖短信/邮件场景
  • 格式变更需维护
