实现方案

范围：发现页（真实 API）+ 我的页 + 编辑资料 + 设置

A
两屏并行，一个 Plan 推荐
Discover + Profile 同时规划，一次交付
后端 1 个新接口 前端 5 个新文件 约 4-5 小时
  • 一次性完成两个 Tab
  • 共享新增用户 API
  • 路由结构一起规划
  • Plan 较大
  • 需同时新增后端
B
先 Profile，再 Discover
分两个 Plan，Profile 无需新后端先交付
Plan 1：纯前端 Plan 2：后端 + 前端
  • Profile 快速交付
  • 每个 Plan 更小更清晰
  • 需写两个 Plan
  • 后端修改推迟
C
Profile 完整 + Discover 仅 UI
Discover 用 mock 数据，后端接口单独迭代
无后端改动 Discover 需二次开发接 API
  • 零后端依赖
  • UI 先验证
  • Discover 做两遍
  • 与你选择"真实数据"矛盾

推荐 A：Profile 和 Discover 共享后端用户接口，一次规划更高效
