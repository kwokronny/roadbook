# 小肥路书 · 吉祥物设计 Brief

**Date:** 2026-04-10
**动物:** 猫鼬 (Meerkat)
**用途:** APP Logo、App Icon、Wordmark、启动页、空状态插图

---

## 1. 角色定位

「小肥」是一只好奇的猫鼬旅行家。猫鼬天生爱站岗张望、探索环境，完美对应旅行规划 APP 的"发现世界"主题。性格：好奇、友好、悠闲、微微撒娇。

---

## 2. 核心姿态：趴窗探头

獴趴在一个窗沿/边框上，只露出**头部 + 两只前爪**，好奇地往上/往外张望。

- 头部占画面主体，约 60-70%
- 两只前爪搭在边沿上，能看到小肉垫
- 身体藏在边框后面，不可见
- 视线方向：微微抬头向上看，表达"好奇看世界"

**用途场景：**
- App Icon：獴从图标底部圆角探出，圆角边缘就是"窗台"
- 登录页：獴从某个 UI 元素后面探头
- 空状态：獴从画面底部探出

## 3. 配色

### 毛色
| 部位 | 色值 | 描述 |
|------|------|------|
| 身体主色 | `#D4B896` | 温暖沙棕色 |
| 头顶/背部 | `#B89B6A` | 深棕色，形成层次 |
| 口鼻/胸前 | `#F0E0C8` | 浅米色，柔软感 |
| 耳朵内侧 | `#C4A87A` | 中棕色 |
| 下巴/喉部 | `#F5EAD6` | 最浅的奶白色 |

### 面部细节
| 部位 | 色值 | 描述 |
|------|------|------|
| 眼斑（猫鼬标志） | `#5C4A32` | 深棕色椭圆包围眼睛 |
| 眼球 | `#1C1C1E` | 近黑色，大而圆 |
| 眼睛高光 | `#FFFFFF` | 右上方主高光 + 左下方次高光 |
| 鼻子 | `#3C3022` | 深褐色，椭圆形，带微小白色高光 |
| 腮红/胡须纹 | `#E8A0A0` 20% | 两侧 2-3 条短横线，淡粉色 |
| 嘴巴 | `#8B7355` | 微笑弧线 |

### 与品牌色关系
- 獴的沙棕色调与 APP 的 Warm Canvas (`#F2EDE8`) 背景和谐
- 獴自身不使用 Coral (`#FF6B3D`)，品牌色通过背景和 UI 元素体现
- 黑色眼睛与 Dark Pill (`rgba(28,28,30,0.88)`) 呼应

---

## 4. 面部表情

### 默认表情：好奇微笑
- **眼睛**：大而圆，占面部比例大（约脸宽的 1/3）。瞳孔大，高光明显。不是圆溜溜的正圆，微微偏椭圆。
- **眉毛**：无。通过眼斑的形状暗示表情。
- **鼻子**：小巧椭圆，位于口鼻区顶部中央。有一个微小的白色高光点。
- **嘴巴**：简单的微笑弧线（ω 形或简单上弧）。不露齿。
- **耳朵**：小圆耳，略向两侧。内侧浅色。
- **胡须/腮红**：两侧各 2 条短横线，淡粉色，增添可爱感。

### 可选表情变体（未来扩展）
- 眯眯眼（开心/享受）
- 惊讶（嘴巴 O 形）
- 打瞌睡（眼睛半闭）
- 戴墨镜（度假模式）

## 5. 爪子细节

- 两只前爪搭在边沿上
- 能看到 3-4 个小肉垫（深一度的棕色圆点）
- 可选：微小的爪纹短线
- 爪子圆润，不尖锐

## 6. Logo 组合方式

### 纯形象（Logo Mark）
- 仅獴，无背景，无文字
- 透明底
- 适用：水印、favicon、小尺寸场景

### App Icon
- **背景**：大自然渐变
  - 蓝天版：`#A8D8EA` → `#C9E4F0` → `#E2D5B8` → `#D4C4A0`（天空→远山→草地）
  - 暖色版：`#FFB088` → `#FFCBA4` → `#F5E0C0` → `#E8D0A8`（夕阳色调）
- **自然元素**：远山剪影轮廓 + 可选白色云朵
- **文字**：上方区域白色"路书"二字，PingFang SC Medium
- **獴**：从底部圆角探出头，爪子搭在边缘
- 圆角：iOS 标准 (continuous corner radius)

### Wordmark（文字组合）
- 獴头像（正面或四分之三侧面）+ "小肥路书"文字
- 横排，獴在左，文字在右
- 文字：PingFang SC Light (w300), 与 APP Display 字重一致

## 7. 尺寸规范

| 用途 | 尺寸 | 注意事项 |
|------|------|----------|
| App Icon (iOS) | 1024×1024 → 各种缩放 | 小尺寸仍需辨识獴的眼睛 |
| Favicon | 32×32, 16×16 | 极简：可能只保留眼睛+头顶轮廓 |
| 启动页 | 全屏居中 | 獴 + 下方"小肥路书"文字 |
| 导航栏 | 32×32 | 纯头像 |

## 8. 风格参考

- **盒马 APP icon**：实心填充、饱满轮廓、简洁细节、一眼辨识
- **参考图中的猫鼬**：大黑眼圈、圆润、友好表情
- **设计规范**：与 Frosted Warmth 设计系统协调（温暖色调、干净、premium 感）
